# For Her ❤️

A romantic, responsive single-page website built around the four uploaded photos.

## Files
- index.html — page structure and love letter
- style.css — glassmorphism, 3D hover, animations, responsive layout
- script.js — scroll reveals, floating hearts, button interactions and 3D tilt
- images/her-1.jpeg ... her-4.jpeg — uploaded photos

## Run
Open `index.html` in a browser.

No build system is required. Internet is only needed for the Google Fonts used by the design; the website itself works without a framework.

Performance update:
- Photos converted to optimized WebP.
- Removed expensive SVG turbulence/noise rendering.
- Reduced backdrop blur and continuous animation workload.
- Floating hearts are capped and pause when the tab is hidden.
- 3D tilt is desktop-only.
